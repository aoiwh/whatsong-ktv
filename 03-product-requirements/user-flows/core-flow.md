# WhatSong｜我颂——核心用户流程

## 一、主流程

```mermaid
flowchart TD
    A[打开 WhatSong] --> B{曲库是否已有歌曲?}
    B -->|否| C[粘贴文本批量导入]
    B -->|是| D[进入筛选]
    C --> E[系统解析歌名]
    E --> F{解析结果是否正确?}
    F -->|否| G[手动修正 / 删除 / 合并重复]
    F -->|是| H[确认导入]
    G --> H
    H --> I[给歌曲打标签]
    I --> D
    D --> J[勾选标签组合]
    J --> K{是否有筛选结果?}
    K -->|否| L[减少标签或清空重筛]
    L --> J
    K -->|是| M[查看筛选结果]
    M --> N[创建 KTV 场次]
    N --> O[场次内调整选歌]
    O --> P[唱完一键反馈]
    P --> Q[反馈默认只存本场次]
    Q --> R{是否手动同步到全局标签?}
    R -->|是| S[手动同步]
    R -->|否| T[结束]
    S --> T
    P --> U[系统自动累计演唱次数]
    U --> T
