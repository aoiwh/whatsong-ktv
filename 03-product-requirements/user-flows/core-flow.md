# WhatSong｜我颂——核心用户流程

## 一、主流程

```mermaid
flowchart TD
    A[打开 WhatSong] --> B{曲库是否已有歌曲?}
    B -->|否| C[粘贴文本批量导入]
    B -->|是| D[进入筛选]
    C --> E[系统解析歌名]
    E --> F{解析结果是否正确?}
    F -->|否| G[手动修正 / 删除 / 合并重复]
    F -->|是| H[确认导入]
    G --> H
    H --> I[给歌曲打标签]
    I --> D
    D --> J[勾选标签组合]
    J --> K{是否有筛选结果?}
    K -->|否| L[减少标签或清空重筛]
    L --> J
    K -->|是| M[查看筛选结果]
    M --> N[创建 KTV 场次]
    N --> O[场次内调整选歌]
    O --> P[唱完一键反馈]
    P --> Q[反馈默认只存本场次]
    Q --> R{是否手动同步到全局标签?}
    R -->|是| S[手动同步]
    R -->|否| T[结束]
    S --> T
    P --> U[系统自动累计演唱次数]
    U --> T
```

## 二、导入流程

```mermaid
flowchart TD
    A[进入导入页] --> B[粘贴文本]
    B --> C{文本是否为空?}
    C -->|是| D[提示：请粘贴歌单文本]
    C -->|否| E[按行/分隔符解析]
    E --> F{是否解析出歌名?}
    F -->|否| G[提示：未识别到歌名，可手动添加，保留原文]
    F -->|是| H[展示解析预览]
    H --> I{是否存在重复?}
    I -->|是| J[自动标记，用户选择保留或合并]
    I -->|否| K[用户手动修正]
    J --> K
    K --> L[确认导入]
    L --> M[进入打标签]
```

## 三、筛选流程

```mermaid
flowchart TD
    A[进入筛选页] --> B[勾选标签组合]
    B --> C[选择且/或逻辑]
    C --> D[查看结果]
    D --> E{是否有结果?}
    E -->|否| F[提示：没有匹配歌曲，试试减少标签]
    F --> G[一键清空]
    G --> B
    E -->|是| H[将结果加入本场次]
    H --> I[进入场次详情]
```

## 四、场次与反馈流程

```mermaid
flowchart TD
    A[创建场次] --> B[填写场次名称/日期]
    B --> C[选择场合类型 可选]
    C --> D[选择同行人类型 可选]
    D --> E[从筛选结果添加歌曲]
    E --> F[调整歌曲顺序]
    F --> G[唱完逐首反馈]
    G --> H[一键稳/一般/翻车]
    H --> I[反馈默认只存本场次]
    I --> J[系统自动累计演唱次数]
    J --> K{是否同步到全局标签?}
    K -->|是| L[手动选择同步]
    K -->|否| M[结束]
    L --> M
```

## 五、关键规则说明

- 系统只自动累计每首歌的演唱次数，不自动计算熟练度。
- 系统不自动生成标签，不自动修改全局标签。
- 场次反馈默认只保存在本场次。
- 用户可手动选择是否将本场次反馈同步到全局标签。
- 筛选支持多标签组合，逻辑可切换“且/或”。
- 导入不联网搜索歌曲，仅解析用户粘贴的文本。
