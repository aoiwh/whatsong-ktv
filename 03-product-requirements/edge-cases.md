# WhatSong｜我颂——异常场景与兜底方案

## 一、导入环节

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 粘贴内容为空 | 用户未输入任何文本 | 不进入解析，停留在导入页 | “请粘贴歌单文本” |
| 粘贴内容全是空白/符号 | 无有效字符 | 不进入解析 | “未识别到有效内容，请检查后重试” |
| 解析不出任何歌名 | 文本格式特殊或全是描述 | 保留原文，提供手动添加入口 | “未识别到歌名，可手动添加” |
| 歌名重复 | 同一首歌出现多次 | 自动标记重复项，用户选择保留一首或全部保留 | “发现 X 首重复歌曲” |
| 歌名含歌手名、序号、符号 | 如“01. 后来 - 刘若英” | 提供手动修正入口，保留原始文本 | “可手动修正歌名” |
| 歌名含表情、特殊字符 | 如“🎵后来🎵” | 自动过滤无关符号，保留有效文字 | 无 |
| 粘贴内容过长 | 超过单次解析上限 | 分批解析，提示用户分次导入 | “内容较长，已分批处理” |
| 解析结果部分错误 | 歌名被截断或合并 | 提供逐条编辑、删除、合并 | “可逐条修正” |

## 二、标签环节

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 用户未打任何标签 | 导入后直接跳过 | 不强制打标，允许进入筛选 | “未打标签的歌曲不会被筛选命中” |
| 标签名重复 | 新增同名标签 | 阻止创建，提示已存在 | “该标签已存在” |
| 标签名为空 | 输入为空 | 阻止保存 | “标签名不能为空” |
| 标签数量过多 | 用户新增大量标签 | 不硬性限制，但提示建议精简 | “标签过多可能影响筛选效率” |
| 删除已被使用的标签 | 标签已挂在歌曲上 | 二次确认，删除后从歌曲上移除 | “该标签已用于 X 首歌，确认删除？” |
| 单首歌标签过多 | 超过建议值 4 个 | 允许保存，但提示建议精简 | “单首歌建议不超过 4 个标签” |

## 三、筛选环节

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 筛选无结果 | 标签组合过严 | 提示减少标签，提供一键清空 | “没有匹配歌曲，试试减少标签” |
| 未选任何标签 | 用户直接点筛选 | 展示全部歌曲 | “未选择标签，已展示全部” |
| 且/或逻辑切换后无结果 | 逻辑变化导致结果为空 | 保留上次结果，提示可切换逻辑 | “切换逻辑后无结果，可返回上一组” |
| 筛选结果过多 | 标签太少 | 允许，提供二次筛选 | 无 |
| 筛选结果中无已打标签歌曲 | 歌曲未打标 | 提示先打标签 | “先给歌曲打标签，筛选才有结果” |

## 四、场次环节

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 场次名称为空 | 未填写 | 默认“未命名场次 + 日期” | 无 |
| 日期未选 | 未填写 | 默认当天 | 无 |
| 场合类型未选 | 未填写 | 允许跳过，不强制 | 无 |
| 同行人类型未选 | 未填写 | 允许跳过，不强制 | 无 |
| 场次内无歌曲 | 未添加任何歌曲 | 允许保存空场次，提示可继续添加 | “场次暂无歌曲” |
| 场次内歌曲重复 | 同一首歌被加两次 | 提示重复，用户选择保留一首 | “该歌曲已在本场次中” |
| 场次中途退出 | 未保存 | 保留草稿，下次进入可继续 | “已保存草稿” |
| 误删场次 | 删除操作 | 二次确认，提供撤销 | “确认删除该场次？” |

## 五、反馈环节

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 未反馈直接退出 | 场次内歌曲未反馈 | 保留未反馈状态，下次可继续 | 无 |
| 重复反馈 | 同一首歌多次点击 | 以最后一次为准 | 无 |
| 反馈后想修改 | 用户改主意 | 允许修改，覆盖上次结果 | 无 |
| 同步到全局标签时冲突 | 全局已有同名标签 | 提示冲突，用户选择覆盖或跳过 | “全局已有同名标签” |
| 同步到全局标签时误操作 | 用户误点同步 | 提供撤销入口 | “已同步，可撤销” |
| 用户不想同步 | 直接跳过 | 默认不同步，反馈只存本场次 | 无 |

## 六、数据与系统

| 异常场景 | 触发条件 | 兜底方案 | 用户提示 |
|---|---|---|---|
| 无网络 | 离线状态 | 已导入数据可本地查看和筛选，场次反馈本地暂存 | “当前离线，数据将在联网后同步” |
| 数据同步失败 | 网络中断 | 本地保留，联网后重试 | “同步失败，已保留本地数据” |
| 误删歌曲 | 删除操作 | 提供回收站或撤销 | “已删除，可撤销” |
| 应用崩溃 | 异常退出 | 本地草稿自动保存 | 无 |
| 数据为空 | 首次使用 | 引导进入导入页 | “先导入你的歌单吧” |

## 七、产品规则兜底

- 系统只自动累计每首歌演唱次数，不自动计算熟练度。
- 系统不自动生成标签，不自动修改全局标签。
- 场次反馈默认只保存在本场次，用户可手动同步到全局标签。
- 导入不联网搜索歌曲，仅解析用户粘贴的文本。
- 标签不硬性限制总数，单首歌建议不超过 4 个。
- 不强制注册登录，不强制打标，不强制反馈。
