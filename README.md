# WhatSong｜我颂

> KTV 私人选歌与演唱沉淀助手

## 项目状态

- 阶段：项目启动
- 类型：C 端轻量工具
- 定位：轻量化、私人化、基于自定义标签的 KTV 选歌与演唱沉淀工具

## 核心问题

1. 个人歌单零散，难以集中管理与快速调用
2. 临场选歌纠结，缺少 KTV 专属筛选维度
3. 演唱经验无沉淀，每次都是从零开始

## 核心流程

> 待补充：粘贴文本批量导入 → 打标签 → 临场筛选 → 创建场次 → 填写反馈 → 更新熟练度与次数

## MVP 范围

- 粘贴文本批量导入歌单
- 基础固定标签 + 用户自由自定义标签
- 多标签组合筛选曲目
- KTV 场次快照记录
- 场次内填写演唱反馈，可选同步更新全局曲目标签
- 歌曲累计演唱次数统计

## 暂不做

- 联网搜索歌曲
- 全网曲库接入
- 音乐播放功能
- 歌词展示
- 社交分享、好友推荐
- AI 自动打分、自动生成标签
- 复杂数据分析报表
