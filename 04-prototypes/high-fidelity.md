# WhatSong｜我颂——高保真原型设计说明

## 一、设计目标

- 极轻量，不增加认知负担
- 打开即用，不做复杂引导
- 视觉克制，不花哨，不喧宾夺主
- 与产品定位一致：私人、轻量、KTV 场景

## 二、视觉规范

### 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | #6C5CE7 | 按钮、选中态、强调 |
| 主色浅 | #EFECFD | 选中背景、标签底 |

| 主文字 | #1A1A1A | 标题、正文 |
| 次文字 | #6B6B6B | 说明、辅助信息 |

### 字体

- 中文：系统默认（苹方 / 思源黑体）
- 英文/数字：SF Pro / Inter
- 字号：
  - 标题：18px / 600
  - 正文：15px / 400
  - 辅助：13px / 400
  - 标签：12px / 500

### 圆角与间距

- 卡片圆角：12px
- 按钮圆角：8px
- 标签圆角：6px
- 基础间距：8 / 16 / 24

### 图标

- 线性风格，1.5px 描边
- 尺寸 20px / 24px
- 底部导航图标 + 文字

## 三、页面设计说明

### 页面 1：我的曲库

**结构：**
- 顶部栏：标题 WhatSong，右侧导入按钮
- 搜索框
- 快捷筛选标签（拿手 / 慎点 / 合唱 / 热场）
- 歌曲列表：歌名 + 标签 + 演唱次数
- 底部导航：曲库 / 筛选 / 场次 / 统计

**交互：**
- 点击歌曲进入详情
- 点击快捷标签直接筛选
- 点击导入进入批量导入
- 长按歌曲可快速打标

### 页面 2：批量导入

**结构：**
- 顶部栏：标题 + 取消
- 粘贴文本框（大号）
- 解析预览区：显示识别数量、重复数量
- 逐条修正入口
- 底部：手动添加 + 确认导入

**交互：**
- 粘贴后自动解析
- 重复项高亮标记
- 点击单条可编辑
- 确认导入后进入打标签引导（可跳过）

### 页面 3：标签管理

**结构：**
- 顶部栏：标题 + 新增
- 预设标签区
- 自定义标签区
- 每个标签右侧：编辑 / 删除

**交互：**
- 点击标签可重命名
- 删除已使用标签需二次确认
- 新增标签即时生效

### 页面 4：筛选

**结构：**
- 顶部栏：标题 + 清空
- 按维度分组：场合 / 嗓子 / 形式 / 风险
- 每组内标签横向排列
- 逻辑切换：且 / 或
- 底部：结果数量 + 加入本场次

**交互：**
- 多标签可同时勾选
- 无结果时提示减少标签
- 结果可一键加入场次

### 页面 5：新建场次

**结构：**
- 顶部栏：标题 + 取消
- 场次名称
- 日期
- 场合类型（可选）
- 同行人类型（可选）
- 已选歌曲列表
- 底部：创建场次

**交互：**
- 名称和日期默认值
- 场合和同行人可跳过
- 创建后进入场次详情

### 页面 6：场次详情

**结构：**
- 顶部栏：场次名 + 日期
- 本场歌曲列表
- 每首歌右侧三个按钮：稳 / 一般 / 翻车
- 底部：同步到全局标签（可选）

**交互：**
- 一键反馈
- 反馈默认只存本场次
- 同步需手动确认
- 可调整歌曲顺序

### 页面 7：统计

**结构：**
- 顶部栏：标题
- 演唱次数排序列表
- 每首歌显示累计次数 + 最近一次演唱时间

**交互：**
- 按次数排序
- 不做复杂图表
- 不做推荐

## 四、核心交互原则

- 每个页面只做一件事
- 主操作按钮始终在底部固定
- 次级操作放顶部或收起
- 空状态给明确引导
- 反馈必须有即时视觉回应
- 不做多层弹窗，不做复杂动画
