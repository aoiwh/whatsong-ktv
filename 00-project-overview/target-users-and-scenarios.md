# WhatSong｜我颂——目标用户与核心场景

## 核心用户画像

- 年龄：18-30 岁
- 身份：大学生、年轻职场人
- KTV 频率：每月至少 1 次
- 会唱歌曲：20 首以上
- 记歌习惯：备忘录、微信收藏、聊天记录、KTV 点歌机收藏
- 社交场景：朋友局、同事局、社团局、相亲局、家庭局
- 核心诉求：场合适配、避免翻车、快速选歌、经验沉淀

## 非目标用户

- 专业歌手、KTV 从业者
- 只听歌不唱歌的人
- 想找全网曲库、想在线录唱的人
- 愿意用 Notion/Excel 复杂维护的人

## 三个核心使用场景

### 场景 1：去 KTV 前 10 分钟

- 人物：小林，24 岁，职场新人
- 触发：晚上要和同事去 KTV
- 目标：嗓子一般，不想唱太高，想选几首稳的独唱
- 现有做法：翻备忘录，凭记忆选，到了现场还是纠结
- 痛点：没有场合和嗓子维度，无法快速筛
- 期望：勾选“同事局 + 嗓子一般 + 独唱”，直接出 5-10 首

### 场景 2：已经在包间里，临场选歌

- 人物：阿哲，22 岁，大学生
- 触发：朋友局冷场，需要热场
- 目标：快速找几首能带动气氛、自己又会唱的歌
- 现有做法：点歌机排行榜推荐，但很多不会唱
- 痛点：公共热度不等于个人会唱
- 期望：按“热场 + 拿手 + 合唱”筛选，立刻点歌

### 场景 3：唱完后，沉淀经验

- 人物：小周，26 岁，常参加聚会
- 触发：一场 KTV 结束
- 目标：记住哪些歌稳、哪些翻车、下次别再踩坑
- 现有做法：不记录，下次继续凭感觉
- 痛点：经验零沉淀，重复翻车
- 期望：在本次场次中一键反馈“稳 / 一般 / 翻车”，反馈保存在本场次；系统自动累计该歌曲演唱次数；用户可手动选择是否将本次反馈同步到全局标签（如“拿手”“慎点”），不自动修改全局标签
