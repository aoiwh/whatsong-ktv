# WhatSong｜我颂——竞品对比表

## 一、竞品范围说明

本项目的竞品不只是“音乐 APP”，还包括用户实际在用的替代方案。按场景分为四类：

1. 通用记录工具：备忘录、微信收藏、Excel、Notion/飞书
2. 听歌类音乐 APP：网易云、QQ 音乐
3. 线上录唱类：全民 K 歌、唱吧
4. 线下 KTV 场景：KTV 点歌机
5. 同类私人选歌工具：K歌本（GitHub 开源）、Reprise、karakeeper

## 三、逐类分析

### 1. 通用记录工具（备忘录 / 微信收藏 / Excel / Notion）

**优势：**
- 用户已经在用，零学习成本
- 灵活，想怎么写就怎么写

**短板：**
- 备忘录是长文本，无分类、无标签、无法筛选
- Excel / Notion 可以搭，但学习成本和维护成本高
- 都不服务于 KTV 临场场景，无法快速筛选

**用户原话：**
- A：“备忘录就是一大段文字，没有分类，想删或者归类太麻烦。”
- C：“像 Notion 那种复杂知识库我直接放弃。”

**结论：** 这是最大的替代方案，也是最大的竞品。WhatSong 的机会不是比它们更灵活，而是比它们更“专用 + 低门槛”。

### 2. 音乐 APP（网易云 / QQ 音乐）

**优势：**
- 曲库全、播放体验好
- 用户已经在用歌单功能

**短板：**
- 服务“听歌”场景，不服务“演唱”场景
- 歌单里混杂“能听”和“能唱”的歌，无法区分
- 没有难度、场合、嗓子、翻车风险这些维度

**用户原话：**
- B：“网易云歌单是听歌用的，不是 KTV 专用，里面有些歌能听但现场不好唱，没法区分。”

**结论：** 错位场景，不构成直接竞争，但会占用用户的歌单使用。

### 3. 线上录唱类（全民 K 歌 / 唱吧）

**优势：**
- 有录唱、打分、作品沉淀

**短板：**
- 偏线上独唱，不解决线下 KTV 多人社交场景
- 不帮助用户临场选歌
- 打分机制与 WhatSong 用户“拒绝被评判”的诉求相反

**结论：** 场景不同，不构成直接竞争。

### 4. KTV 点歌机

**优势：**
- 就在包间，点歌方便
- 有排行榜、分类、收藏

**短板：**
- 推荐基于公共热度，不匹配个人会唱的歌
- 收藏跨店失效
- 无私人标签、无场次记录、无演唱反馈

**用户原话：**
- A：“推荐都是热门新歌，很多我根本不会唱。”
- B：“点歌机收藏只能当前门店，换 KTV 就清空。”

**结论：** 是 WhatSong 的互补场景，不是竞品。WhatSong 负责“选”，点歌机负责“点”。

### 5. 同类私人选歌工具

#### K歌本（GitHub 开源）

**功能：** 搜索歌曲建立个人档案（星级 + 适合调 + 备注）、今晚唱队列、统计、分享歌单。

**与 WhatSong 的差异：**
- K歌本：逐首搜索建立档案，录入成本高
- WhatSong：粘贴文本批量导入，录入成本低
- K歌本：只有星级 + 适合调两个维度
- WhatSong：预设标签（拿手/慎点/合唱/热场）+ 自定义
- K歌本：无赛后一键反馈
- WhatSong：场次内一键反馈，可选同步全局标签

#### Reprise

**功能：** 场景筛选、自动标签、评分等级、Tonight's Queue、Performance Journal、隐藏唱过的歌。

**与 WhatSong 的差异：**
- Reprise：英文产品，不支持中文
- WhatSong：中文市场，覆盖同事局、长辈局等本地社交场景
- Reprise：有评分等级（Still learning → Showstopper），带评判感
- WhatSong：不自动打分，只用“稳/一般/翻车”一键反馈
- Reprise：未强调批量导入
- WhatSong：粘贴文本批量导入，不局限于备忘录

#### karakeeper

**功能：** 按标签、文件夹整理歌曲，构建 setlist，支持离线搜索和云同步。

**与 WhatSong 的差异：**
- karakeeper：无赛后反馈
- WhatSong：场次内一键反馈
- karakeeper：偏重歌单整理
- WhatSong：偏重临场筛选 + 经验沉淀
- karakeeper：英文
- WhatSong：中文，本地社交场景

## 四、竞品结论

1. 用户最大的替代方案是备忘录、微信收藏和音乐 APP歌单。
2. 录唱 APP、点歌机都错位场景，不构成直接竞争。
3. 同类私人选歌工具（K歌本、Reprise、karakeeper）验证了需求真实存在，但各有空白：
   - K歌本：无批量导入
   - Reprise：英文
   - karakeeper：无赛后反馈
4. WhatSong 的差异化是：
   - 粘贴文本批量导入（不局限于备忘录）
   - 中文本地社交场景标签（同事局、长辈局）
   - 不自动打分、不自动计算熟练度
   - 场次内一键反馈，可选同步全局标签
   - 系统只累计演唱次数
   - 极轻量，拒绝复杂维护
